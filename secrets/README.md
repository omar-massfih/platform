# Secrets

Real credentials are git-ignored. Never commit them.

| Input / Kubernetes Secret | Purpose |
|---|---|
| `ghcr.pat` -> `platform/ghcr` | Image pull token, provisioned by the Ansible ghcr_secret role |
| `omarmassfih-backend.env` -> `platform/omarmassfih-backend` | Optional AI Gateway credential, provisioned by app_secrets |
| `platform/pg-app` | Generated by CloudNativePG; backend, RPG and Keycloak database access |
| `platform/keycloak-admin` | Out-of-band bootstrap credentials: `username`, `password` |
| `platform/oauth2-proxy` | Out-of-band `OAUTH2_PROXY_CLIENT_ID`, `OAUTH2_PROXY_CLIENT_SECRET`, `OAUTH2_PROXY_COOKIE_SECRET` |
| `flux-system/ghcr` | Registry token used by RPG image reflection; keep synchronized on rotation |
| `flux-system/platform-git` | Repository write credential used by Flux image automation |

Preserve existing Keycloak realm/client configuration and proxy secrets during
cleanup. Retired-service secrets and old Codex authentication data are not
recreated by Ansible and have not been erased from the VM.
